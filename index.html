AI-assisted backlog refinement

Explore how an AI critique can help a team spot unanswered questions before implementation — while keeping decisions with the people doing the work.

Transparency: This interactive page displays illustrative, prewritten findings. It is not connected to a live AI model. Run the prompt in the repository with an approved AI tool to capture a genuine AI response.

1. Backlog item

Fictional example: e-commerce password reset.

2. What to examine

  • Missing requirements and acceptance criteria
  • Assumptions that need validation
  • Edge cases and security considerations
  • Dependencies and delivery risks
  • Questions for Product Owner, developer, and tester

AI output is a starting point for discussion, not a source of truth or an automatic readiness decision.

Illustrative sample output

Potential gaps to validate

  • What happens if the email address is not registered?
  • Does the reset link expire, and what is the expiry period?
  • Can a reset link be reused?
  • What password rules must be met?
  • How should repeated reset requests be handled?
  • What prevents account enumeration or unauthorized access?

Questions for refinement

  • What is the expected behavior for invalid or expired links?
  • What password validation rules apply?
  • Are rate limits and security controls required?
  • What email delivery and response-time expectations apply?

Provisional assessment

Needs clarification — illustrative judgment only. The Product Owner, development team, and relevant security expertise should validate the business rules and acceptance criteria before deciding readiness.
