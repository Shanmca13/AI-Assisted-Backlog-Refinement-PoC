**Can AI help a Scrum Master ask better questions before a sprint begins? I built a small proof of concept to explore that question.**

Inspired by a workflow idea in SAFe Connect's *AI Toolsday: Real AI, Real Agile, Real Workflows*, I created an AI-assisted backlog refinement demo using a fictional password-reset feature.

The workflow is designed to help surface:
- Missing requirements and assumptions
- Edge cases and security considerations
- Questions for the Product Owner, developer, and tester
- Dependencies and delivery risks

The principle is simple: **ask AI to challenge the story, not just rewrite it.**

The AI's suggestions still need human review. The team owns the context, validates the rules, and makes the readiness decision.

This is an initial personal learning PoC using fictional data, not a production implementation. I've documented the workflow, prompt, and review template in the repository.
