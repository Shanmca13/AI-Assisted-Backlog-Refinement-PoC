# Sample backlog item (fictional)

## User story
As a registered customer, I want to reset my password using my registered email address so that I can regain access to my account.

## Original acceptance criteria
1. Customer can request a password reset.
2. A reset email is sent.
3. Customer can set a new password.

## Context
- Application: fictional e-commerce service
- Business objective: help customers regain account access
- Dependencies: email delivery service (assumed; validate)
- Technical notes: none supplied
- Known constraints: none supplied

## Deliberate limitations
This story is intentionally incomplete to demonstrate how a critique can surface questions. Suggested findings are not confirmed business rules.
